# 昨日涨停今日买入策略

## 📖 策略说明

基于 A 股市场涨停板效应的动量策略，捕捉涨停股的次日溢价。

## 🎯 策略逻辑

### 选股条件
1. T 日收盘价涨停（根据板块区分涨停幅度）
2. 按市值从大到小排序
3. 选前 N 只（默认 10 只）

### 涨停判定
| 板块 | 代码特征 | 涨停幅度 |
|------|----------|----------|
| 主板 | 000xxx, 600xxx | 10% |
| 科创板 | 688xxx | 20% |
| 创业板 | 300xxx | 20% |
| 北交所 | 8xxxxx, 4xxxxx | 30% |
| ST 股票 | 名称含 ST | 5% |

### 买入时机
- T+1 日开盘价买入

### 卖出条件（满足任一）
1. **止损**：亏损 ≥ -5%
2. **止盈**：盈利 ≥ +15%
3. **回撤止盈**：从最高点回撤 ≥ -5%
4. **超期**：持有 ≥ 5 天

## ⚙️ 策略参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `max_positions` | 10 | 最大持仓数 |
| `stop_loss_rate` | 0.05 | 止损 5% |
| `take_profit_rate` | 0.15 | 止盈 15% |
| `trailing_stop_rate` | 0.05 | 回撤止盈 5% |
| `max_hold_days` | 5 | 最多持有 5 天 |
| `min_volume` | 100 | 最小交易单位（手）|
| `price_add` | 0.05 | 下单价格调整 5% |

## 🚀 使用方法

### 1. 导入策略

```python
from vnpy.strategies.limit_up_strategy import LimitUpStrategy
```

### 2. 配置参数

```python
setting = {
    "max_positions": 5,           # 减少持仓数
    "stop_loss_rate": 0.07,       # 放宽止损到 7%
    "take_profit_rate": 0.20,     # 提高止盈到 20%
}
```

### 3. 准备信号数据

```python
import polars as pl

# 信号数据格式
signal_df = pl.DataFrame({
    "datetime": [datetime(2024, 1, 1), ...],
    "vt_symbol": ["000001.SZSE", ...],
    "signal": [1.0, ...],              # 涨停=1，其他=0
    "market_cap": [100000000000, ...]  # 市值
})
```

### 4. 添加到回测引擎

```python
from vnpy.alpha.strategy import BacktestingEngine

engine = BacktestingEngine(lab)
engine.add_strategy(LimitUpStrategy, setting, signal_df)
```

## 📊 回测结果（示例股票池 2023-2025）

| 指标 | 值 |
|------|-----|
| 总收益率 | -3.82% |
| 交易次数 | 2 次 |
| 胜率 | 0% |
| 最大回撤 | 9.24% |

**注意**: 示例股票池较小（12 只），实际建议使用全市场股票。

## ⚠️ 注意事项

1. **数据需求**：需要完整的日线数据（含前收盘价）
2. **涨停判定**：需根据板块区分涨停幅度
3. **流动性**：建议增加成交额过滤（如>1 亿）
4. **实盘风险**：涨停股次日可能高开太多，买不进去

## 🔧 优化建议

1. **增加筛选条件**：
   - 成交量放大（> 前一日 1.5 倍）
   - 非一字板（有换手）
   - 封板时间早（14:00 前）

2. **优化买入**：
   - 集合竞价买入
   - 设置开盘涨幅阈值（如 -2% ~ +7%）

3. **优化卖出**：
   - 次日不涨停就卖出
   - 尾盘卖出（14:50）
